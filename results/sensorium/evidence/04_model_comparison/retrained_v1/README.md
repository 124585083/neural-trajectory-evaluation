# Immutable source-run evidence

These files record the completed `retrained_v1` source run. The original Static epoch-59 model, Dynamic epoch-109 model, preprocessing, neural GPFA and main model-comparison results retain their recorded identities.

**The response-matching portion of this source run is superseded.** Its `response_matching_selection.csv`, `pilot/response_matching_*` tables and matching fields in the frozen analysis, summary and status record belong to the earlier output-noise method. Their values remain historical evidence and are not the current checkpoint-matching result.

The active method and results are [Goal 05 setup](../../../05_response_matching/SETUP.md) and [Goal 05 results](../../../05_response_matching/RESULTS.md). Its separate evidence is [checkpoint_matching_v1](../checkpoint_matching_v1/). The [source audit](../checkpoint_matching_v1/source_audit.json) identifies published dependencies at the original Git commit.

The [archived method](../../../05_response_matching/HISTORICAL_OUTPUT_NOISE_SETUP.md) and [archived results](../../../05_response_matching/HISTORICAL_OUTPUT_NOISE_RESULTS.md) preserve the original interpretation and numerical tables. Existing checksums and dated verification records identify the original artifacts; they do not certify the new checkpoint control.
