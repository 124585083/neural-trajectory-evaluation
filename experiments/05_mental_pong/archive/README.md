# Historical Mental-Pong experiments

Read the [version history](HISTORY.md) for executed analyses before the final condition-mean endpoint comparison. It preserves the original FA reproduction, fixed GPFA64 hidden-direction study, average-behavior previews, old segmented-candidate OLS and repeated trial-label analysis. The [closeout ledger](../trajectory_project/closeout_v1/experiment_ledger.md) connects these questions to the final tests.

Original reports and manifests remain externally preserved, with source IDs and hashes in the [migration map](../integration/migration_map.csv). This archive contains English publication summaries rather than bilingual duplicates. It records earlier protocols without treating them as interchangeable with final FA50/GPFA50 results. Required executable dependencies from older stages remain in working packages rather than being classified as history-only code.

The active scientific conclusion is the [final closeout report](../trajectory_project/closeout_v1/FINAL_REPORT.md). Future work is consolidated in the [cross-study plan](../../../docs/FUTURE_DIRECTIONS.md).
